# تماريني — Tamareeni PWA

تطبيق تمارين عربي للجوال يعمل على GitHub Pages دون اشتراكات أو خادم، مبني لجدول **Upper A / Lower A / Upper B / Lower B**.

## المميزات

- جدول شخصي 4 أيام: السبت علوي A، الأحد سفلي A، الثلاثاء علوي B، الخميس سفلي B. الاثنين والأربعاء والجمعة للراحة أو المشي/الكارديو حسب التعافي.
- عرض آخر أوزان وعدات **مسجلة** (مع تاريخها)، واستخدام الوزن السابق كبداية للحصة الجديدة مع ترك حقل العدات فارغًا حتى تُدخل الأداء الحقيقي.
- تسجيل وزن وعدات كل جولة على حدة، تعليم الجولات المكتملة، إضافة جولات وحذفها، وتدوين ملاحظات التمرين والحصة.
- حفظ تلقائي للحصة المفتوحة داخل الجهاز حتى عند إغلاق التطبيق.
- مؤقت الحصة، مؤقت راحة 60/90/120/180 ثانية، وتنبيه صوت/اهتزاز عند اكتماله *إذا سمح المتصفح وكان مفتوحًا*.
- **زر «إنهاء الحصة ونسخ الملخص»**: يحفظ التمرين وينسخ ملخصًا كاملًا جاهزًا لواتساب، مع زر مشاركة مباشر في سجل الحصص.
- سجل لكل الحصص، الحجم التدريبي (كغ × عدات)، آخر 8 أسابيع، قياس الوزن ومحيط الخصر، وسجل كارديو/خطوات.
- تعديل البرنامج والجولات والتمارين وترتيبها، مع عرض عدد الجولات المخططة لكل يوم.
- استيراد/تصدير نسخة احتياطية **JSON** وتصدير سجل الجولات **CSV**.
- قابل للتثبيت على شاشة الهاتف كـ PWA، ويعمل دون اتصال بعد زيارة أولى عبر HTTPS.

## الجدول المعتمد — الإصدار 5 (8 نوفمبر 2026)

**الهدف: موازنة عدد الجولات على الأيام الأربعة، بدون زيادة غير ضرورية أثناء التنشيف والمشي الكثير.**

- **Upper A (السبت): 20 جولة** — Chest Press 3×8–12؛ Pec Fly 3×10–15؛ Lat Pulldown 3×8–12؛ Seated Row 2×10–12؛ Cable Lateral Raise 3×12–20؛ Face Pull 2×12–15؛ Triceps Machine 2×10–15؛ Biceps Curl Machine 2×10–15.
- **Lower A (الأحد): 20 جولة** — Leg Press 3×10–12؛ Leg Extension 3×10–15؛ Leg Curl 4×10–12؛ Hip Adductor 2×12–15؛ Standing Calf Raise 3×12–15؛ Abdominal Crunch Machine 3×10–15؛ **Dumbbell Wrist Curl 2×12–20**.
- **Upper B (الثلاثاء): 20 جولة** — Incline Chest Press 3×8–12؛ Chest-Supported Row 3×8–12؛ Shoulder Press 2×8–12؛ Pec Fly 2×12–15؛ Straight-Arm Pulldown 2×12–15؛ Reverse Pec Deck 2×12–20؛ Cable Lateral Raise 2×12–20؛ Dumbbell Hammer Curl 2×10–15؛ Overhead Cable Triceps Extension 2×10–15.
- **Lower B (الخميس): 22 جولة مسجلة** — Leg Curl 4×10–15؛ Glute Machine 3×10–12؛ Single-Leg Press يمين 3×10–12 ويسار 3×10–12؛ Hip Abductor 2×12–15؛ Seated Calf Raise 3×12–15؛ Pallof Press 2×10–12 لكل جهة؛ **Dumbbell Reverse Wrist Curl 2×12–20**. جولات Single-Leg Press تُحسب 3 لكل رجل، ولا تُضاعف عند حساب الحجم العضلي لكل فخذ.

**العدد:** 82 جولة مسجلة على التطبيق = 20 + 20 + 20 + 22؛ تقريبًا 79 جولة لو اعتبرنا عمل اليمين واليسار للتمرين الأحادي 3 جولات لكل رجل. تغيير التوزيع نقل السواعد إلى Lower A وLower B وخفّض Seated Row وBiceps Curl Machine وStraight-Arm Pulldown من 3 إلى جولتين.

الجولات غير المباشرة لا تُحسب تلقائيًا كجولات مباشرة كاملة. يعد الجدول نقطة بداية؛ لا تُرفع الجولات إلا إذا تحسن التعافي وبقيت عضلات محددة بلا تقدم.

**تحديث تلقائي من النسخ السابقة:** عند فتح التطبيق على نفس النطاق والمتصفح، تُحافَظ الحصص السابقة والقياسات والنسخ الاحتياطية. يُنقل Wrist Curl من Upper A إلى Lower A وReverse Wrist Curl من Upper B إلى Lower B، ويُعدَّل عدد جولات التمارين الثلاثة إذا كانت لا تزال على العدد الافتراضي القديم. تبقى الحصة النشطة كما بدأت، ولا تُعاد كتابتها منتصف التمرين. البرامج المعدلة يدويًا يُحافَظ على معظم تعديلاتها.

**ملاحظة أوزان الأجهزة:** البايسبس كيرل (جهاز) والهامر (دامبل) لا يرثان أوزان الكيبل المرجعية القديمة. في هامر دامبل أدخل وزن الدمبل الواحد؛ يحسب التطبيق حجم الرفع لليدين معًا.

**تحديث التطبيق:** إذا استُخدمت نسخة سابقة، يُحدِّث التطبيق تلقائيًا أسماء هذه التمارين واختياراتها في الجدول الافتراضي دون حذف الحصص السابقة. عند وجود تعديلات مخصصة لأسماء التمارين، تبقى كما هي.

**ملاحظة الكتف:** Shoulder Press أصبح موجودًا في Upper B فقط، بواقع جولتين و8–12 عدة. وزن 19 كغ مرجع من 3 نوفمبر وليس طلبًا إلزاميًا. مع ألم مقدمة الكتف السابق، ابدأ بأخف وزن مريح، تجنب مدى الحركة المؤلم، وأوقف التمرين إذا ازداد الألم أو استمر بعده. في حال استمرار الألم أو تكراره راجع طبيبًا أو أخصائي علاج طبيعي.

**التنفس والضغط:** لا تحبس النفس أثناء الرفع، وتجنّب الأوزان القصوى عندما لا يكون ضغط الدم تحت السيطرة. استشر الطبيب إذا كان ضغطك مرتفعًا بشكل غير معتاد.

## نشره مجانًا عبر GitHub Pages

1. فك ضغط ملف `Tamareeni-GitHub-Ready.zip`.
2. افتح [github.com/new](https://github.com/new) وأنشئ مستودعًا جديدًا، مثل `tamareeni`، واختر **Public**.
3. اختر **Add file → Upload files**، ثم ارفع **محتويات المجلد** لا الملف المضغوط. تأكد من وجود `index.html` في جذر المستودع، بجوار `app.js` و`data.js` و`styles.css` ومجلد `icons`.
4. اختر **Commit changes**.
5. في المستودع انتقل إلى **Settings → Pages**؛ اختر **Deploy from a branch**، ثم `main` و`/(root)`، واضغط **Save**.
6. ستجد رابط التطبيق في قسم **Pages**، وصيغته عادةً: `https://YOUR_USERNAME.github.io/tamareeni/` (استبدل اسم المستخدم والمستودع بأسمائك الفعلية). لا تستخدم رابطًا افتراضيًا إلا بعد التأكد أنه ظهر في إعدادات GitHub.
7. افتح الرابط على جوالك. **أندرويد**: Chrome → قائمة ⋮ → تثبيت التطبيق / إضافة للشاشة الرئيسية. **آيفون**: Safari → مشاركة → إضافة إلى الشاشة الرئيسية.

لا يحتاج بناء (`npm` أو GitHub Actions)؛ هذا مشروع HTML/CSS/JavaScript جاهز.

## مهم جدًا: حفظ البيانات

جميع السجلات محفوظة محليًا في المتصفح باستخدام `localStorage`، **وليست محفوظة في GitHub**. لذلك:

- النسخة المنشورة والمثبتة على جوالك تستخدم نفس المصدر إذا فتحتهما من نفس النطاق وعلى نفس المتصفح؛ لكن Safari وChrome قد يحتفظان بنسخ منفصلة.
- لا يتم تزامن البيانات تلقائيًا بين الأجهزة ولا مع GitHub. لا تعتمد على التطبيق وحده إن كانت بياناتك مهمة.
- **إذا جعلت مستودع GitHub عامًا (Public)، فإن الأوزان المرجعية المسبقة في ملف `data.js` ستكون مرئية في الكود المصدري.** الحصص الجديدة التي تدخلها على هاتفك تبقى محلية ولا تُرفع تلقائيًا.
- صدّر ملف **JSON** دوريًا من الإعدادات واحفظه في ملفات هاتفك أو خدمة نسخ احتياطي. عند تغيير الجوال أو المتصفح، استورده من الإعدادات.
- لا تمسح بيانات موقع التطبيق أو تثبته على نطاق جديد قبل أخذ نسخة احتياطية.
- استخدم HTTPS (Github Pages يوفره). تشغيل `index.html` محليًا بالنقر عليه قد لا يعمل بسبب استخدام وحدات JavaScript.

## تشغيل محلي على الكمبيوتر

من داخل المجلد:

```bash
python -m http.server 8000
```

ثم افتح `http://localhost:8000`.

## الملفات

- `index.html` — واجهة التطبيق.
- `styles.css` — التصميم المتجاوب.
- `data.js` — الجدول وأوزان المرجع السابقة المعلومة.
- `app.js` — تسجيل الحصص والتقدم والنسخ الاحتياطي.
- `manifest.webmanifest` — تثبيت التطبيق على الهاتف.
- `sw.js` — التخزين المؤقت والعمل دون اتصال.
- `icons/` — الأيقونات.

المشروع لا يجمع أي معلومات ولا يرسلها إلى طرف ثالث. لا يتضمن تسجيل دخول أو مزامنة سحابية.
